# Looks

Everything about how Glazed Menu looks is in its own settings, which you'll find in its mod list like any other mod's.

## Dark and light

Both modes are complete: every screen, popup and editor has a dark and a light version.

![The config screen in light mode](../assets/shots/config-screen-light.jpg){ .gm-shot loading=lazy }

## More

- **Panel opacity**: how much of the background shows through the panes.
- **Background effects** behind the screens.
- **Page transitions**: screens fade into one another.
